Tier 1/2 • Marketing Site + Automated Systems

The Lazy Creator Company (Main Site)

A growing product portfolio needs a hub site that scales. New products shouldn't require a manual rebuild, and lead capture has to actually deliver, not just show a success message that hides a silent failure.

The Problem

As a product portfolio grows, a hub site either scales with it through enforced structure, or it turns into a pile of one-off page edits every time something new ships. Lead capture forms also frequently look like they work while silently failing to actually deliver anything.

What Was Built

A full navigation and chapter architecture supporting the whole portfolio, with a standing rule enforced in the build itself: every new product automatically gets a full product card, its own accent color, and an updated live-product-count chip, no manual page edits required. Full email automation runs through Brevo, Netlify Functions, and GitHub Actions, including a real production bug found and fixed: a keepalive fetch silently losing a race against native browser navigation on Safari and iOS specifically, meaning signups from the platform's own primary device type were failing invisibly until diagnosed. Distinct, context-specific welcome emails are sent per signup source rather than one generic template.

Tech Stack

Netlify Netlify Functions Brevo GitHub Actions GitHub Contents API

Status

Live — this is the hub site the rest of the portfolio runs through.
