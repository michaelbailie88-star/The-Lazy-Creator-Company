Tier 4 • Two-Sided Marketplace UI/UX

Oddly

Odd-jobs marketplaces live or die on trust and usability. Taskers and employers need a fast, mobile-native way to browse, message, and transact without the app feeling like a spreadsheet.

The Problem

Marketplace apps connecting taskers and employers need to feel fast and trustworthy on a phone specifically, since that's where almost all real usage happens, and mobile web apps are notoriously prone to subtle cross-browser bugs that never show up in desktop testing.

What Was Built

A full mobile-first marketplace interface: a job feed with category filtering, in-app messaging with a thread view, an alerts system, and a complete onboarding flow, alongside a fully custom brand identity, an illustrated SVG wordmark, a deep navy and electric blue palette, and a Nunito type system. Real cross-browser engineering was involved, not just visual design: a back-navigation bug caused by inline styles overriding CSS state, a broken filter-bar selector mismatch, and an iOS Safari scroll-before-paint bug, fixed with a forced layout-reflow, the standard technique for that specific class of bug.

Tech Stack

HTML / CSS / JS (single-file, mobile-first) iOS Safari-hardened Custom SVG brand system

Scope note: UI/UX and interaction design build. Backend and payment infrastructure were scoped but not yet implemented.

Status

Prototype complete. Ready to move into backend implementation as a full two-sided marketplace.
