Tier 2 • Licensed Software Product

Activity Vault

Educators need a large, professionally curated activity library they can license per classroom or school, not a scraped content website with no real pedagogical foundation behind it.

The Problem

Most activity resources for educators are either shallow content mills or paywalled one-off worksheets with no organizing structure. Schools, daycares, and camps need something they can license once and use across staff, built by someone who actually understands early-childhood development, not generic content.

What Was Built

A single-file web application spanning four modules, AdaptED, CampED, TeenagED, and RegulatED, covering 5,330 activities across 128 categories. Content is built directly on 20 years of early-childhood education expertise. Access is license-gated through Gumroad, verified against a Vercel API backend, with Individual and School pricing tiers.

Tech Stack

HTML / JS Gumroad licensing Vercel API backend Netlify

Status

Live, actively selling to schools, daycares, and homeschool families, backed by a 2,521-contact Ontario educator outreach list.
