Tier 2+ • Full-Stack SaaS, Custom Logic Engine

Kingdom Radar

Christian creators and ministries can't tell which content topics are actually worth their time. Most tools either guess or hand the whole decision to an AI black box.

The Problem

Faith-based creators and organizations need a way to know which topics, audience needs, and Scripture connections are actually worth building content around, not a generic keyword tool and not a tool that quietly makes the call with an opaque AI model neither the builder nor the buyer can audit.

What Was Built

A deterministic weighted-scoring engine, entirely rule-based logic, zero AI model calls at runtime, scoring every content opportunity across six weighted factors: topic (30%), audience (20%), emotion (15%), scripture (15%), format (10%), and seasonal timing (10%). Behind it sits a full Postgres/Supabase schema with row-level security and relational join tables, a React/Vite dashboard with eight functional sections plus an admin panel, and full Stripe checkout, webhook, and self-serve billing-portal integration. The content layer alone spans 36 topics and 1,008 structured records.

Tech Stack

React Vite Tailwind Supabase / Postgres Row-Level Security Vercel Stripe (Checkout, Webhooks, Portal)

Status

Live in production, Stripe running in live mode, confirmed end-to-end with a real completed transaction through checkout, webhook, and database.
