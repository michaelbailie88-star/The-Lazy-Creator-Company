Mock Build

HairStylz by Jodie

A salon portfolio and booking-style concept mockup — built to show what a real client site could look like for a local hair stylist, not a live client engagement.

View Live Mockup →

The Problem

Most independent stylists are stuck choosing between two bad options: no website at all (just an Instagram bio link), or an expensive template-builder site that looks generic and still doesn't make booking any easier for the client.

The Solution

A single-page salon site built around three things a stylist's site actually needs: a real photo gallery to show the work, a clear service menu with pricing, and a booking-style flow that guides a visitor toward actually reaching out — instead of a phone number buried at the bottom of the page.

Tech Stack

HTML / CSS / JS Hand-coded, no page builder Mobile-first Netlify-ready

What This Is Designed To Do

This is a concept mockup, not a live client site, so there are no real booking numbers to report. What it demonstrates: a gallery-first layout suited to visual businesses, a service menu that removes back-and-forth pricing questions, and a mobile-first build since most salon clients are browsing from their phone.
