Hosting

Where it actually lives

Netlify Hosting / Static

Drag-and-drop static site hosting, no server to manage, no CLI required. This exact site runs on it.

Why I use it: I work mobile-first, and Netlify Drop lets me ship a real live site straight from a zip file, no computer required.
Visit Netlify →
Vercel Hosting / Apps

Hosting for real applications, anything with a backend, a database connection, or server-side logic that a static site can't handle.

Why I use it: GitHub-connected deploys mean every push goes live automatically, with instant rollback if something breaks.

Railway Hosting / Backend

Backend and pipeline hosting for anything that needs to run continuously in the background, not just serve pages.

Why I use it: Simple enough to deploy from mobile, powerful enough to run a real automated content pipeline behind the scenes.
